Как считается рейтинг

Source: основной источник — официальный журнал Vanilla Game `/lk/sieges`; локальные Minecraft-логи остаются fallback-режимом для ручного пересчёта.

Deaths: в официальном режиме смерти берутся из серверного журнала участников осады; в fallback-режиме учитываются ванильные смерти внутри официального окна Aden до лимита 10 смертей игрока за осаду.

Target Strength: сглаженный KD + поправка на размер выборки, затем percentile внутри осады.

Kill Value = 1 + 2 × percentile1.4.

Upset: +10% / +20% / +35% при преимуществе силы цели ≥20 / ≥30 / ≥50 процентных пунктов.

Farm: повторные убийства одной слабой/средней цели постепенно дешевеют.

Final = DAK × QualityIndex0.35.

Season: месячная сумма Final за осады выбранного месяца. Avg: отдельный рейтинг по среднему Final за сыгранные осады этого же месяца.

Нажмите на строку игрока, чтобы открыть карточку. Заголовки таблицы сортируются кликом.

Skin preview: NameMC link + внешний Minecraft skin renderer fallback. Статический сайт, без аккаунтов пользователей.
